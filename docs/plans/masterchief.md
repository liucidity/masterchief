## Design

### Overview

Kind: note.
Fidelity: full.

MasterChief is a commander that turns individual AI assistants into an organized engineering crew across all your projects.; Goals; One command deck over every project.; Dedicated agents per task: coding, testing, review, investigation.; Every agent in its own Git worktree, so nothing collides.; Two mission types: Build and Investigate.; A permanent Second in Command (Cortana) for oversight.; Non-goals (v1); Not a new coding model or IDE.; No cross-machine cluster; one host first.; No auto-merge to main without a human or Cortana gate.

### Build mission flow

Kind: flow.
Fidelity: sketch.

### Investigate mission flow

Kind: flow.
Fidelity: sketch.

1 Question or bug report submitted; 2 Commander lists hypotheses; 3 Investigators probe in parallel (read-only worktrees); 4 Reproduce end to end, collect evidence; 5 Cortana: evidence sufficient?; 6 Findings report; 7 Optional: spawn a Build mission from the findings

### Cortana oversight

Kind: note.
Fidelity: full.
